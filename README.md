# Dashboard quản lý camera CVSG

Dashboard theo dõi tình trạng hệ thống camera của Trung tâm Cờ Vua Sài Gòn.

## Dữ liệu

- Nguồn: sheet **Quản lý camera**, vùng **A:K**.
- Tổng số dòng: **16.041**.
- Chỉ loại những dòng trống hoàn toàn.
- Dữ liệu được chia thành `data-1.js`, `data-2a.js` và `data-2b.js` để GitHub tải ổn định.

## Chức năng

- Lọc theo tháng hoặc khoảng ngày.
- Chọn nhanh tháng hiện tại.
- Lọc theo cơ sở, người phụ trách và tình trạng.
- KPI lượt kiểm tra, lượt bất ổn, camera bị ảnh hưởng, khắc phục và minh chứng.
- Biểu đồ diễn biến theo ngày.
- Danh sách camera cần ưu tiên xử lý.

Mở `index.html` hoặc bật GitHub Pages từ nhánh `main`, thư mục `/(root)`.
